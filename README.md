# SmartComplaintResolver
Smart Complaint Resolver is a backend application developed using Spring Boot that allows users to create, manage, and resolve complaints efficiently. The system provides secure authentication, complaint tracking, analytics, real-time notifications, and AI-based complaint categorization.
Features

✅ User Authentication & Authorization using Spring Security + JWT
✅ Complaint Registration & Tracking
✅ AI-Based Complaint Categorization using Spring AI
✅ Real-Time Notifications with WebSockets
✅ RESTful APIs
✅ Analytics Dashboard APIs
✅ Role-Based Access Control
✅ Complaint Status Management
✅ Comment & History Tracking
✅ Scalable Backend Architecture using Microservices Concepts
